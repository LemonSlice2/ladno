# Ладно.

Telegram Mini App для @lladno_bot. Статический интерфейс; финансовые записи находятся только в браузере на устройстве. В репозитории должны находиться только код, иллюстрации и вымышленные примеры.

## GitHub Pages

В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root), затем Save. Адрес появится в этом же разделе после успешного развёртывания. Файл .nojekyll отключает обработку Jekyll. Все адреса ресурсов относительные, поэтому приложение работает в подпапке репозитория.

## Telegram

После проверки HTTPS-адреса в BotFather используйте /setmenubutton, выберите @lladno_bot, задайте адрес GitHub Pages и текст «Открыть Ладно.». Для кнопки в профиле настройте Main Mini App в параметрах бота. Токен бота не нужен для этих ручных шагов и не должен находиться в репозитории.

## Ограничения

Это локальный прототип без серверной Telegram-авторизации и синхронизации. GitHub Pages размещает только статические файлы. Для облачных записей потребуется отдельный сервер с проверкой initData и авторизацией доступа к каждому бюджету. WebView разных Telegram-аккаунтов не следует считать безопасно разделёнными хранилищами. Экспортируйте JSON перед очисткой браузера и переносом устройства.

Порядок счетов меняется стрелками на карточках, сохраняется отдельно для каждого бюджета и используется в списках выбора счёта. Приложение всегда использует светлую палитру.

Финансовая логика и адаптер проверены 63 автоматическими проверками. Настройка бота и запуск внутри настоящего Telegram требуют проверки после публикации.
